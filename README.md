C# & Friends

A ten-day, one-hour-a-day experiment in AI-assisted technology reacquisition.

I'm using modern C#/.NET to build and ship a small real-world application, Diorama Continuity. The question isn't whether I can learn C#. It's whether ten focused hours, working aggressively with AI but accepting no code I can't explain, can reduce the language and framework to the point where they're no longer meaningful friction between me and the engineering problem.

This repository captures the product, its engineering artifacts, the commit history, and the research notes—including where AI helped and where it got things wrong.
